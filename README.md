# COS10026 Lab 08

This exercise uses a PHP login form, a session, a hidden field, and include files.

## Run with XAMPP

1. Put the `lab08` folder in `htdocs` and start Apache.
2. Open `http://localhost/lab08/login.php`.
3. Use `YourName` as the username and `YourStudentID` as the password, or replace those values in `process.php` with your own details.

The login page uses the `.php` extension because PHP must run its `include` statements. The hidden field contains the example token `abc123`.

Open the pages through XAMPP, view the generated HTML in the browser, and check it with the [W3C Nu Validator](https://validator.w3.org/nu/).
